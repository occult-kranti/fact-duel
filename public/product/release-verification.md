The competitive engine and 500ms active polling transport remain the existing private-pilot implementation. No new load test is claimed for this visual release. Existing local stress results do not certify Cloudflare D1 throughput, public concurrency or WAN latency.

Not performed in this iteration: browser/physical-device play, 320–430px rendered QA, assistive-technology evaluation, 200% zoom observation, actual graphics-driver loss, frame/battery measurements, cross-location human matches, or retention/learning studies. Responsive CSS, semantic controls, fallback paths and unit tests do not substitute for these checks. They remain P15/P16/P18 and R16/R19 in the roadmap.
