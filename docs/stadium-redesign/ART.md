# Art provenance

Two original environment assets were generated with the built-in image-generation tool for this project on29October2026. They depict an invented stadium, no real player likeness or sponsor identity. Local deliverables: public/art/stadium-day.webp and stadium-night.webp,900×1200,230664 and217090bytes respectively. PNG originals are preserved outside the source tree; WebP is the deployed derivative.

Creative brief: polished miniature3D Indian cricket stadium; high view behind the batting crease; emerald striped oval and ochre wicket; terracotta/cream architecture; fine crowd texture; premium physically shaded diorama aesthetic; empty space above the ground; no logos, UI or text. Day uses warm afternoon sunlight/blue sky/unlit towers. Night uses deep navy sky, illuminated floodlights, aqua shafts and warm architectural light. The exact image is an illustrative game environment, not an accurate simulation of a real venue.

Runtime art uses compressed local files plus CSS perspective and separately computed ballistic ball paths. The app does not run an image generator while playing. Figma retains editable native UI around imported art. Generated concepts are not claimed as product screenshots; browser screenshots in verification show the implemented product.
