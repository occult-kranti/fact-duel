# JHK voice and exact copy

Updated 30 October 2026. The default presentation uses short Roman Hinglish as requested. Hindi-script equivalents remain in the existing Hindi locale. Functional navigation, controls, rules, errors, privacy, eligibility and score receipts remain explicit. These are proposed or source-inspected strings, not a claim that every optional string below has shipped.

## Voice contract

Confident, playful and cricket-aware. Challenge the boast at entry; support the person after an attempt. A button names the action rather than performing a joke. Use one short headline plus one factual supporting line. Avoid making everyone read a long chant before the first over.

Use **Gyaan** consistently in Roman copy. Use **Mini over — 3 rounds** and **Full over — 6 rounds** as the stable format names. Reserve “club points,” “team points,” “XP,” and “trophies” for the actual respective balances; do not substitute one for another to make the reward sound larger. “Local” does not imply a geographic ranking unless the server actually records and ranks that location.

## Further strings for results and club support

These options are approved tone examples for later targeted use; do not describe them as implemented without a source change and review.

| Context | Exact string | Placement limit |
| --- | --- | --- |
| Settled win headline | `Scorecard pe naam.` | Only beside a real settled winning score; no global rank implication. |
| Optional winning share caption | `Gyaan ka scorecard. Tera challenge?` | Attach the actual format and score. The user initiates sharing; no automatic challenge acceptance. |
| Settled ordinary loss | `Aaj unki innings. Agla over tumhara.` | Respectful metaphor; show the truthful loss and actual score first. “Next” means an optional opportunity, not a promised win. |
| Defined close loss | `Bas itna sa faasla.` | Only when the result model classifies a close loss; never every defeat. |
| Draw | `Barabar ka game. Dono ka naam.` | Only for an actual draw. A cup tie advanced by seed must retain the disclosed tie rule. |
| Wrong-answer explanation | `Yeh fact agle over ke kaam aayega.` | Show the correct answer and source. Avoid a joke that obscures what was wrong. |
| Reserve encouragement | `Club mein jagah. Agli sheet ka mauka.` | Immediately clarify that this fixture's selected side alone can contribute. No false promise of selection. |
| Club camp heading | `Baat ab team ki hai.` | Decorative heading only; current phase and next valid action stay explicit. |
| Optional crest chooser heading | `Rang apna. Game wahi.` | Explain palettes are cosmetic; score, timer and question access stay equal. |

The existing cricket result moment already uses respectful distinct win, wicket, close-loss and draw copy. Replacing every line is unnecessary; retain a coherent single result voice rather than stacking several slogans around the same score.

## Avoid

Do not use `Asli fan hota toh jeetta`, `Itna bhi nahi aata?`, `Loser`, `Come back or lose your title`, invented “fans online,” fake countdown urgency, guaranteed wins, purchased rescue after a loss, or a share message that exposes a private invitation or implies the recipient already joined. Do not call cosmetic club colors “lucky” in a way that implies better odds. Keep scandal-topic copy distinct from findings and allegations; playful tone does not erase source qualifications.

## Review gates

1. Read the words in their actual screen context, not only in this table. Verify that Mini and Full retain their correct round counts and XP conditions and that bot/human and browser/server boundaries remain explicit.
2. At 320px and 390px, confirm the hero is legible, the action names remain visible, and neither a long headline nor an ornament obstructs the first clear action. Review Hindi script as well as Roman Hinglish.
3. Confirm selected club palette, result state and errors remain understandable without distinguishing hue. Inspect actual computed foreground/background pairs where translucency or art changes the surface.
4. Check errors, a wrong answer, loss, draw, reserve state and skipped weekly draft: the competitive voice must not become humiliation, a false result, forced replay or surprise enrollment.

Audience comprehension and tone preference require actual user testing. A source review, a panel round and a passing layout test are different evidence types and must be reported separately.
