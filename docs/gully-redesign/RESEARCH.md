# Design rationale and source record

Reviewed 29 October 2026. These are source-informed product decisions and AI review perspectives, not human participant results. No claim is made to have read whole copyrighted books, to have built a scientifically optimal interface, or to have proved retention uplift.

| Reference | Applied judgment | Observable check |
| --- | --- | --- |
| Steve Krug, [Don't Make Me Think, Revisited, author page](https://sensible.com/dont-make-me-think/) | A clearly labelled dominant action and purpose-based navigation reduce decisions before useful play | Fresh home→one click→question; all routes reachable |
| Don Norman, [The Design of Everyday Things, revised edition](https://jnd.org/books/the-design-of-everyday-things-revised-and-expanded-edition/) and [author's preface](https://jnd.org/preface-design-of-everyday-things-revised-edition/) | Explicit signifiers, reversible navigation and immediate answer feedback | Bot label; first-answer lock; Cancel/Leave/Replay; visible network errors |
| Nielsen Norman Group, [progressive disclosure](https://www.nngroup.com/articles/progressive-disclosure/) and [recognition vs recall](https://www.nngroup.com/articles/recognition-and-recall/) | Reveal specialist setup and collections on request, retain familiar names inside task groups | Native details preserve settings; contextual directory preserves routes |
| W3C, [WCAG 2.2](https://www.w3.org/TR/WCAG22/) and [Target Size minimum](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) | Aim beyond the24 px minimum with44 px chrome and52 px phone answer targets | Browser target bounds, keyboard focus, enlarged text, no horizontal overflow |
| W3C, [Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html) | Quiet timed play; respect reduced-motion preferences | No decorative movement on questions; reduced-motion rules |
| Google, [AdSense on gameplay pages](https://support.google.com/adsense/answer/2768340?hl=en) and [placement policies](https://support.google.com/adsense/answer/1346295?hl=en) | Obvious play controls; no display inventory on gameplay; future manual footers away from controls | Zero ad requests with defaults; no ad DOM/gap; detailed activation document |
| [React](https://react.dev/learn), [Lucide](https://lucide.dev/guide/), [Excalidraw](https://github.com/excalidraw/excalidraw) and [Playwright](https://playwright.dev/docs/intro) official sources | Retain established accessible components, existing icon language, editable source board, repeatable browser checks | Compile/build, native board export, scripted interaction evidence |

The art direction is an original combination of a gully-cricket poster and match scorebook. It is a design choice, not a claim that the underlying quiz mechanics are unprecedented. Existing source-backed facts and human-authority boundaries are preserved.

Impeccable SKILL.md was read. Its context launcher and referenced new-work/craft-floor files were unavailable in this installation. Existing source, prior design documents and screenshots were used directly; no successful launcher/context or absent reference read is claimed. Its replacement-world, real-artwork and bounded-verification principles guided the implementation.
