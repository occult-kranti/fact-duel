# Artwork provenance

Two original bitmap assets were generated using the built-in image generation tool before implementation. No copied player photo or existing club logo was used. These are illustration and UX references, not factual diagrams or a claim that any depicted player endorses the game.

## UX concept

Final project reference: `docs/gully-redesign/ui-concept.webp`.

Prompt: Create a polished UI reference board for JAANTA HAI KYA, a mobile-first cricket knowledge game. Desktop homepage and mobile active question side by side. Indian gully cricket club meets contemporary match-day scorebook: warm paper #f8f3e7, near-black navy #182630, vermilion orange, tobacco yellow and small teal accents. Expressive sans serif typography, chapter navigation, scorebook rules and asymmetric composition. Homepage title “All talk? Prove it.”, a dominant “Play cricket” action, smaller “Human duel”, clearly labelled practice. Flat risograph batter artwork. Mobile question has score, practice-bot label, timer, one question and four full-width separated answer controls. No ads near game controls, no glow, gradients, 3D or purple. Implementable interface reference.

The mockup's sample question, numbers and illustrated UI are conceptual. The application uses real DOM text, actual server/local game state and its existing editorial bank; none of the image's sample statistics were imported as product claims.

## Homepage illustration

Final asset: `public/art/gully-cricket.webp`, 960×960, approximately 216 kB. Generated source PNG was encoded to WebP for the game. This is a format/size derivative of the original generation, not a replacement placeholder. The same illustration is embedded in the editable Excalidraw scene.

Prompt: One square editorial risograph artwork, no text. A dynamic cricket batter in a vermilion orange shirt, navy helmet and cream trousers follows through a powerful shot with a wooden bat; a large cream red-seamed ball arcs in the foreground. Compact Indian urban cricket ground, rooftops, one floodlight and graphic crowd marks. Warm ivory #f8f3e7, deep navy #182630, vermilion #d94d2b, muted ochre #cba352, small slate teal. Bold flat shapes, subtle printed ink grain, strong diagonal action, commissioned sports-poster feel. No photorealism, 3D, gradients, glow, UI, border, typography, logos or watermark. Character centered right, credible bat/body proportions, warm ivory background.

The generated anatomy is artistic and the artwork is decorative (`alt=""`). The home renders actual playable controls before the artwork. It is absent from the active question screen; a failed image load cannot block the game.
